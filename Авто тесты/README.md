# Проект «Профиль» — приложение под тесты

Небольшое приложение для итогового задания: студенты пишут к нему **API-** и
**UI-тесты**. Внутри — вход по e-mail (код приходит в ответе бэка), обязательная
анкета и профиль с редактированием.

## Как запустить

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

pip install -r requirements.txt
python app.py
# открыть http://localhost:5001
```

Для тестов (в отдельном окружении/терминале):

```bash
pip install -r tests-requirements.txt
playwright install                # только для UI-тестов
```

## Как работает

Сценарий пользователя:

1. вводит e-mail → бэк «отправляет» код (в демо код возвращается в ответе и
   показывается на странице);
2. вводит код → получает доступ;
3. заполняет **анкету** (имя, фамилия, возраст, город, о себе) — без неё профиль
   недоступен;
4. попадает в **профиль**, где данные можно **редактировать**.

Приложение одновременно отдаёт JSON API (`/api/...`) и HTML-страницы, поэтому к
нему пишут и API-, и UI-тесты.

## API-контракт

| Метод и путь | Тело запроса | Успех | Ошибки |
|---|---|---|---|
| `POST /api/auth/request-code` | `{"email"}` | `200 {email, code, message}` | `400` неверный email |
| `POST /api/auth/verify` | `{"email","code"}` | `200 {token, profile_completed}` | `400` неверный код |
| `POST /api/questionnaire` | `{first_name,last_name,age,city,bio?}` + `Authorization: Bearer <token>` | `201 {profile}` | `401` без токена, `400` валидация |
| `GET /api/profile` | `Authorization: Bearer <token>` | `200 {profile}` | `401` без токена, `403` анкета не заполнена |
| `PATCH /api/profile` | любые поля профиля + токен | `200 {profile}` | `401`, `403`, `400` |

Профиль: `{email, first_name, last_name, age, city, bio}`.
Валидация: e-mail по формату, возраст — целое число 1–119, поля анкеты обязательны.

## UI-страницы

| Страница | Что на ней есть |
|---|---|
| `/` | поле **Email**, кнопка **Получить код** |
| `/verify` | код в элементе `data-testid="demo-code"`, поле **Код**, кнопка **Войти** |
| `/questionnaire` | поля **Имя, Фамилия, Возраст, Город, О себе**, кнопка **Сохранить анкету** |
| `/profile` | данные профиля (`data-testid="profile-*"`), форма редактирования, **Выйти** |

Элементы снабжены `label` и `data-testid`, чтобы локаторы Playwright
(`get_by_label`, `get_by_role`, `get_by_test_id`) были простыми и устойчивыми.

## Примеры тестов

В папке `examples/` — по одному эталонному тесту, чтобы показать подход:

- `example_api_test.py` — полный API-сценарий (вход → анкета → профиль →
  редактирование) и негативный кейс с неверным кодом;
- `example_ui_test.py` — тот же путь через браузер.

Это только образец. Основную часть покрытия студенты пишут сами.

## Задание

Написать набор автотестов к этому приложению: **API-тесты** (requests + pytest) и
**UI-тесты** (Playwright). Оформить как репозиторий с папкой `tests/`, `README` и
инструкцией запуска.

Что стоит покрыть (минимум):

**Авторизация**
- запрос кода на корректный e-mail — `200`, в ответе есть `code`;
- запрос кода на некорректный e-mail — `400`;
- верификация с правильным кодом — `200`, приходит `token`;
- верификация с неправильным кодом — `400`.

**Анкета**
- профиль до анкеты — `403`;
- успешное заполнение — `201`, данные сохранились;
- валидация: пустые обязательные поля и некорректный возраст — `400`
  (используйте параметризацию).

**Профиль**
- получение профиля с токеном — `200`, корректные поля;
- запрос без токена — `401`;
- редактирование поля (например, города) — `200`, значение изменилось.

**UI (Playwright)**
- полный happy-path: вход по коду → анкета → профиль;
- проверка, что без анкеты пользователь не попадает в профиль;
- редактирование профиля отражается на странице.

Требования к сдаче:
- `pytest` из корня проходит зелёным (приложение запущено локально);
- тесты названы по смыслу, есть и позитивные, и негативные кейсы;
- вынесены повторяющиеся шаги (логин) в функции/фикстуры;
- короткий `README` с командами запуска.

Будет плюсом: параметризация, фикстуры для токена/базового URL, трасса
Playwright для одного из UI-тестов.
